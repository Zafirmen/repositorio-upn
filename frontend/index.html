Proceso

¿Cómo funciona?

El flujo para publicar un proyecto en el repositorio es simple y estandarizado.

01

Crear una rama

Crea una rama con el formato feature/nombre-proyecto desde main. Los usuarios externos hacen fork primero.

02

Agregar archivos

Incluye metadata.json, banner.jpg y contenido.md dentro de la carpeta de tu licenciatura.

03

Abrir Pull Request

Crea un PR hacia main con un título descriptivo. Solicita revisión al administrador.

04

Revisión y publicación

El revisor verifica la estructura y aprueba el PR. Tu proyecto queda publicado en el repositorio.
