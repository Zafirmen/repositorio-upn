## Propósito del repositorio

Este repositorio alberga los proyectos académicos, recursos técnicos y documentación generados por las licenciaturas adscritas al Departamento de Tecnología. Su finalidad es centralizar, preservar y difundir los trabajos desarrollados por docentes y estudiantes autorizados.

---

## Estructura del repositorio

El repositorio se organiza por licenciaturas. Cada licenciatura contiene carpetas de proyectos, y cada proyecto respeta una estructura estandarizada que incluye metadatos, archivo de descripción y recursos visuales.

```
/tecnologia-upn
├── /licenciaturas
│   ├── /diseno_tecnologico
│   ├── /informatica_educativa
│   └── /tecnologia_e_industria
├── /_templates
├── /frontend
├── /docs
├── README.md
├── CONTRIBUTING.md
└── SECURITY.md
```

## 📋 Templates

Antes de subir un proyecto, utilice las siguientes plantillas disponibles en la carpeta `_templates/`:

| Template | Uso |
|----------|-----|
| [metadata.json](./_templates/metadata.json) | Metadatos obligatorios del proyecto (título, autores, tecnologías) |
| [contenido.md](./_templates/contenido.md) | Plantilla de documentación académica del proyecto |

## Políticas de uso

| Rol | Permiso |
|-----|---------|
| Administrador | Creación de licenciaturas, gestión de equipos, aprobación de Pull Requests |
| Docentes registrados | Creación de proyectos, apertura de Pull Requests |
| Usuarios autorizados | Lectura del repositorio, fork, apertura de Pull Requests desde fork |

**Regla fundamental:** Ningún usuario puede escribir directamente sobre la rama `main`. Todas las contribuciones requieren un Pull Request con revisión.
