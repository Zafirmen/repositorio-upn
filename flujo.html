Flujo de Publicación

Un estándar claro para garantizar la calidad y preservación.

01

Crear una rama

Crea una rama con el formato feature/nombre-proyecto desde main. Usuarios externos deben hacer fork primero.

02

Preparar Archivos

Incluye el manifiesto metadata.json, una imagen banner.jpg y el texto contenido.md en el directorio asignado.

03

Pull Request

Abre el PR hacia main detallando los cambios y solicitando la revisión oficial.

04

Exhibición

Tras la aprobación, el proyecto se fusiona y se despliega automáticamente en esta galería.
